# Интерфейс

Каталог `frontend/` — React + Vite + TypeScript. В solution не входит. Страницы лежат в `frontend/src/pages/`.

Язык и часовой пояс описаны в [locale.md](locale.md). Запросы к API ходят через `frontend/src/api.ts` и при необходимости несут `Authorization` и `Accept-Language`.

## Маршруты

| Путь | Экран | Доступ |
|---|---|---|
| `/` | Список вопросов | Все |
| `/questions/:id` | Карточка вопроса и ответы | Все |
| `/questions/new` | Новый вопрос | Только вошедший |
| `/questions/:id/edit` | Правка своего вопроса | Только автор |
| `/login` | Вход | Гость |
| `/register` | Регистрация | Гость |
| `/settings` | Язык и часовой пояс | Все |

## Что делает каждая страница

**Список** — фильтры по теме, состоянию (`все` / `открытые` / `отвеченные`), сортировке и поиску по заголовку. У каждой строки видно число ответов и, отмечен ли лучший.

**Карточка** — текст вопроса, ответы (лучший сверху), форма нового ответа для вошедшего. Автор вопроса может отметить лучший ответ или снять отметку. Автор записи может править и удалять своё.

**Форма вопроса** — заголовок, текст и тема. После сохранения открывается карточка.

**Вход и регистрация** — сохраняют токен в браузере. После входа интерфейс показывает имя и кнопки «Задать вопрос» и «Выйти».

**Настройки** — переключатель `ru` / `en` и выбор часового пояса для показа времени. Выбор остается в браузере и не пишется в базу.
