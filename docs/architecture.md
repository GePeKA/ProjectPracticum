# Предметная область

В сервисе три сущности: пользователь, вопрос и ответ.

Пользователь входит по email. Рядом с вопросами и ответами видно только имя. Пароль хранится как хеш.

Вопрос состоит из заголовка, текста и одной темы. Темы фиксированы: учёба, быт, город, техника и другое. У вопроса один автор.

Ответ — это текст к конкретному вопросу. У ответа свой автор. На один вопрос может ответить несколько человек, и один человек может ответить больше одного раза.

Автор вопроса отмечает один чужой ответ как лучший. Свой ответ отметить нельзя. Лучший ответ всегда один: новая отметка снимает предыдущую. Вопрос считается отвеченным, когда лучший ответ выбран. Наличие обычных ответов само по себе вопрос не закрывает.

Удалить или изменить вопрос и ответ может только их автор. Вместе с вопросом исчезают его ответы.
